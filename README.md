# 🚀 Featured Projects

## ☕ Java & Object-Oriented Programming

My projects demonstrate how Java OOP concepts can be applied to real-world systems.

### 🏥 Comprehensive Hospital Management System
A Java-based system designed to model hospital operations using multiple interacting classes.

- **Key Concepts:** Encapsulation, Abstraction, Inheritance, Polymorphism, Interfaces, Class relationships, Real-world object modelling
- **Main Components:** `Patient` · `Doctor` · `Nurse` · `MedicalTechnician` · `Consultation` · `Treatment` · `Medication` · `Surgery` · `MedicalBill`

---

### 📚 Digital Library Management System
A Java OOP project that models a digital library environment and different types of library users and media.

- **Key Concepts:** Inheritance, Polymorphism, Abstraction, Object relationships, Library resource management
- **Main Components:** `Book` · `AudioBook` · `DVD` · `MediaItem` · `LibraryUser` · `Student` · `Faculty` · `PublicUser` · `RentalTransaction`

---

### 🛒 E-Commerce Order Processing System
A Java-based OOP project modelling an e-commerce order processing environment.

- **Key Concepts:** Inheritance, Polymorphism, Abstraction, Interfaces, Product modelling, Customer types, Payment strategies, Order processing
- **Main Components:** `Product` · `Clothing` · `Shirt` · `Electronics` · `Laptop` · `SmartPhone` · `Customer` · `RegularCustomer` · `PremiumCustomer` · `Order` · `OrderItem`
- **Payment Components:** `PaymentMethod` · `CreditCardPayment` · `BankTransferPayment` · `DigitalWalletPayment`
