A Java-based system modelling hospital operations through interacting
classes.

**Key concepts:** Encapsulation · Abstraction · Inheritance ·
Polymorphism · Interfaces · Class Relationships

**Main components:** `Patient` · `Doctor` · `Nurse` ·
`MedicalTechnician` · `Consultation` · `Treatment` · `Medication` ·
`Surgery` · `MedicalBill`

------------------------------------------------------------------------

### 📚 Digital Library Management System

A Java OOP project modelling a digital library with different media
types and user categories.

**Main components:** `Book` · `AudioBook` · `DVD` · `MediaItem` ·
`LibraryUser` · `Student` · `Faculty` · `PublicUser` ·
`RentalTransaction`

**Focus:** Inheritance · Polymorphism · Abstraction · Object
Relationships · Resource Management

------------------------------------------------------------------------

### 🛒 E-Commerce Order Processing System

A Java-based OOP project modelling products, customers, orders and
payment methods.

**Main components:** `Product` · `Clothing` · `Shirt` · `Electronics` ·
`Laptop` · `SmartPhone` · `Customer` · `RegularCustomer` ·
`PremiumCustomer` · `Order` · `OrderItem`

**Payment components:** `PaymentMethod` · `CreditCardPayment` ·
`BankTransferPayment` · `DigitalWalletPayment`

**Focus:** Inheritance · Polymorphism · Abstraction · Interfaces ·
Product Modelling · Customer Types · Payment Strategies
